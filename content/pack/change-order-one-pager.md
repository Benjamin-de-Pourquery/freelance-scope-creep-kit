## EN — Change Order Form

```
CHANGE ORDER
============

Change Order No.:     CO-[NUMBER]
Date:                 [DATE]
Original Agreement:   Quote / SOW dated [ORIGINAL DATE]
Project:              [PROJECT NAME]
Client:               [CLIENT LEGAL NAME]
Freelancer:           [YOUR LEGAL NAME / COMPANY]

────────────────────────────────────────────────────────────

1. DESCRIPTION OF CHANGE

   The Client requests the following addition/modification to the original scope:

   [Detailed description of the change — be specific about deliverables,
    formats, platforms, number of revisions, etc.]

2. IMPACT

   Estimated effort:     [X] hours / [Y] business days
   Revised delivery:     [DATE] (if applicable)
   Dependencies:         [Client assets, approvals, access, etc.]

3. FEES

   Additional fee:       [AMOUNT] [CURRENCY] (excl. tax)
   Tax (if applicable):  [RATE]% — [AMOUNT] [CURRENCY]
   Total additional:     [AMOUNT] [CURRENCY] (incl. tax)

   Payment terms:        [Per original contract / 50% upfront / Net 30]

4. EFFECT ON ORIGINAL SCOPE

   All other terms of the original quote/contract remain unchanged.
   This change order forms part of the agreement once signed below.

5. APPROVAL

   By signing below, both parties agree to the terms of this change order.


   Client:                              Freelancer:

   Name:    _________________________     Name:    _________________________
   Title:   _________________________     Title:   _________________________
   Date:    _________________________     Date:    _________________________
   Signature: _______________________     Signature: _______________________
```

## FR — Formulaire d'avenant

```
AVENANT AU CONTRAT / DEVIS
==========================

N° d'avenant :         CO-[NUMÉRO]
Date :                 [DATE]
Contrat initial :      Devis / CCAG / contrat du [DATE INITIALE]
Projet :               [NOM DU PROJET]
Client :               [NOM LÉGAL CLIENT]
Prestataire :          [TON NOM / RAISON SOCIALE]

────────────────────────────────────────────────────────────

1. DESCRIPTION DE LA MODIFICATION

   Le Client demande l'ajout ou la modification suivante au périmètre initial :

   [Description détaillée — livrables, formats, plateformes,
    nombre de retours, etc.]

2. IMPACT

   Charge estimée :     [X] heures / [Y] jours ouvrés
   Nouvelle livraison :  [DATE] (si applicable)
   Prérequis :          [Éléments client, validations, accès, etc.]

3. TARIFICATION

   Montant additionnel : [MONTANT] € HT
   TVA ([TAUX]%) :      [MONTANT] €
   Total TTC :          [MONTANT] € TTC

   Modalités :          [Selon contrat initial / 50% à la commande / Net 30]

4. EFFET SUR LE PÉRIMÈTRE INITIAL

   Toutes les autres clauses du devis/contrat initial restent inchangées.
   Le présent avenant fait partie intégrante de l'accord une fois signé.

5. VALIDATION

   En signant ci-dessous, les deux parties acceptent les termes de cet avenant.


   Client :                              Prestataire :

   Nom :     _________________________     Nom :     _________________________
   Fonction : _________________________     Fonction : _________________________
   Date :    _________________________     Date :    _________________________
   Signature : _______________________     Signature : _______________________
```
